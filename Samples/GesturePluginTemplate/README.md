# Gesture Plugin Template

This is a starter template for building custom plugins for AirGesture AI.

## Getting Started

1. Open this project in Visual Studio or VS Code.
2. Build the project using the .NET SDK:
   ```bash
   dotnet build -c Release
   ```
3. Copy the compiled DLL file from `bin/Release/net8.0-windows/GesturePluginTemplate.dll` into the `Plugins/` subdirectory of your AirGesture AI installation.
4. Restart AirGesture AI to load and enable the plugin.
